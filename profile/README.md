# Wehner Group – Quantum Internet Software

Welcome to the open-source home of the **Wehner Group** at
[QuTech](https://qutech.nl), Delft University of Technology, led by
Prof. Stephanie Wehner.

All software in this organization is **created, used, and contributed to by
members of the Wehner Group** as part of our research toward a scalable,
programmable quantum internet.

## Our mission

A quantum internet will connect quantum processors anywhere on Earth by
distributing entanglement, enabling capabilities that are impossible with
classical communication alone. Our group works to make quantum networks
usable by society by developing the architectures, protocols, and systems
software needed to program and run applications on real quantum network
hardware.

## Full-stack quantum network software

The projects here cover the entire quantum network pipeline:

| Layer | What we build |
|---|---|
| **Applications** | Quantum network applications and example protocols |
| **Programming & compilation** | SDKs, instruction sets, and compilers for quantum network programs |
| **Operating systems** | Software that runs quantum network applications on quantum network nodes |
| **Network & control plane** | Scheduling, routing, and resource management across the network |
| **Link layer** | Protocols for reliable entanglement generation between nodes |
| **Simulation & evaluation** | Simulators, benchmarks, and tools to test the stack before deployment |

Our previous contributions include the first link layer protocol for
quantum networks (ACM SIGCOMM 2019), the NetQASM instruction set
architecture, and QNodeOS, the first operating system for quantum
networks (Nature 2025).
